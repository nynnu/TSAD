# 확대 화면의 증거와 Stage1 후보 연결 실험

## 문제

machine-1-6 case 43에서 후보 [637,651)의 60틱 zoom에 별도 후보 [652,669)가 함께 나타남. 확대 화면에 눈에 띄는 변화가 있다는 것만으로 앞 후보에 그 변화를 귀속할 수 없음. GT는 사후 분석에만 사용했으며 VLM prompt에 넣지 않음.

추가로 기존 통합 DINO 경로의 `contracts.final_prompt`는 보라색 경계가 그림에 표시된다고 설명하고 실제 기본 renderer도 해당 필드가 있으면 경계를 그림. 별도의 `yellow_only_demo`는 보라색 표시를 제거했지만 기존 prompt는 범위가 아닌 확대 화면 자체를 평가함. 두 경로를 같은 입출력 계약으로 보면 안 됨.

## 파일럿

같은 기존 zoom-only 그림을 그대로 사용하고, 보라색 경계를 추가하지 않은 채 후보 시간 범위를 그림의 상대 좌표로 알려줌. VLM에는 판단에 사용한 시각적 증거의 대략적인 상대 시간 구간도 요청함. 범위를 벗어나거나 걸치거나 위치를 모르는 경우 보류하는 실험용 검사를 만들었음. 시간 영역은 시작 포함, 끝 미포함임. 이 검사는 기본 통합 경로에 연결하지 않음.

| 사례 | 상대 좌표 후보 | VLM 응답 | 반환된 증거 구간 | 검사 결과 |
|---|---|---|---|---|
| case 43 | [105,119) | uncertain | [105,119) | uncertain |
| case 1 | [104,121) | anomalous | [104,121) | uncertain |

두 응답 모두 후보 범위를 그대로 반환했음. 독립적인 시각적 위치 추정이라고 확인할 수 없으므로, 결과를 본 뒤 동일한 경계의 복사 응답도 보류하도록 진단 검사를 바꿈. 따라서 이 보류 규칙은 **사후 수정**이며 독립 실험에서 검증된 성능이 아님. 우연히 실제 근거 구간이 후보 범위와 정확히 같을 수도 있으므로 복사 여부만으로 응답이 틀렸다고 단정하지도 않음.

범위 안의 다른 구간을 반환해도 그것이 실제로 이미지에서 읽은 위치라는 보장은 없음. 위치 정답을 직접 검증할 데이터와 사전에 고정한 평가 기준이 필요함. 정상 판정도 이 프로토타입은 자동 확정하지 않음. 결과는 사례당 호출 1회이며, GT를 참고해 사례를 선정했으므로 일반화 성능을 추정할 수 없음. 원래 case 1과 case 43은 서로 인접한 두 후보이므로 독립 사례도 아님.

## 코드와 결과

- `scope_attribution_pilot.py`: 이미지, 후보 범위, VLM 근거 시간 요청과 보수적 보류 검사. 이상 위치 또는 원인 확정 도구가 아님.
- `test_scope_attribution.py`: 범위 밖·경계 걸침·누락·복사·형식 오류에 대한 검사, 3개 통과.
- `results/scope_attribution_20261109/`: 원본 응답과 prompt, 응답 후 수정 전후 검사 결과. 사용한 그림의 SHA-256 저장.

다음 검증에서는 실제 눈에 보이는 변화의 독립적인 시간 주석을 준비하고, 같은 이미지에 알려주는 후보 범위를 달리해 위치 답변이 그림을 따르는지 범위를 따라 움직이는지 비교해야 함. 모델 표시를 없애는 것과 판단 대상 구간을 전달하는 것은 다른 문제임. 현재 결과만으로 Stage1 경계가 개선되었거나, VLM의 후보별 판단을 안전하게 집계할 수 있다고 주장하지 않음.
