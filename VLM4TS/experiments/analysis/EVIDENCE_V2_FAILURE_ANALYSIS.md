# Stage1이 아직 불안정한 이유 — 분포·성분·시간·참조 분석

2026-11-04. SMD machine-1-1/1-2/1-6의 고정된 evidence-v2 모델을 분석했음.
이번에는 detector를 다시 바꾸지 않고 어디서 실패하는지 분리했음.
분포, alpha sweep, 성분 제거, 실제 원본 파형, 구간 연결, train 유사 사례를 확인했음.

## 먼저 확인한 핵심

| 문제 | 실제로 확인한 것 | 수정 방향 |
|---|---|---|
| 일부 장비는 threshold가 너무 높아짐 | 1-2의 보정 상위1%가 ch16의 연속60틱 한 덩어리임 | 채널별 보정과 사건 단위 보정의 영향을 분리해서 검증 |
| 다른 장비는 정상 상태에서도 점수가 계속 높음 | 1-6 정상 경보 시점의 약95.3%에서 ch13이 최고 점수임 | 상태 변화와 실제 이상에 대한 추가 증거·보정 신뢰도 필요 |
| 짧게 끊기는 경보와 길게 붙는 경보가 공존함 | 1-6은 GT29개에 닿지만 일대일 대응은17개임 | 점수 계산과 사건 시작·끝 판정을 별도 설계 |
| review를 넓히면 화면 비용이 크게 늘어남 | 1-2는652장, 같은 시점을 평균6.25회 표시함 | 후보는 보존하면서 겹치는 화면의 중복을 줄이는 스케줄 필요 |
| train reference가 항상 정상의 기준이 될 수 없음 | 정답상 정상인 상태도 train reference와 크게 다를 수 있음 | reference 부적합을 이상으로 확정하지 않고 표시해야 함 |

모두 하나의 원인은 아님. threshold를 일괄 높이거나 낮추면 반대 장비의 문제가
커질 수 있음. 아래 제거 실험도 진단용이며, test F1이 좋은 설정을 골라 적용하지 않았음.

## 1. machine-1-2: 큰 정상 변화 하나가 threshold에 과도한 영향을 줌

Calibration 점수 상위1%는60틱이며, 전부 ch16의 한 연속 구간에서 나왔음.
원본 파형에서는 큰 spike가 확인되며, 점수에서는 그 영향이 여러 이동창에 남았음.
60개의 독립적인 정상 사건을 본 것처럼 해석하면 안 됨.

| dynamic 점수 | calibration | 별도 train audit | test GT-normal | test GT-anomaly |
|---|---:|---:|---:|---:|
| 99% 분위수 | 8.100 | 4.040 | 4.011 | 4.714 |
| 최대값 | 9.914 | 4.478 | 6.097 | 5.286 |

실제 이상의 점수가 정상보다 높은 경향은 있으나, calibration의 아주 큰 정상
사례가 만드는 high 기준에는 못 미침. Alpha .01의 calibration 자체 통과율도
동점 때문에 약0.236%임. 유한 표본 p-value의 보수적인 동점 처리까지 함께 작동함.

이를 확인하려고 동일 fit·calibration 구간에서 성분을 빼고 다시 보정했음.

| 진단 실험 | high 후보 | 일대일 GT 대응 /10 | 실제 이상과 안 겹치는 후보 |
|---|---:|---:|---:|
| 원래 dynamic 결합 | 0 | 0 | 0 |
| variance60만 제외 | 19 | 5 | 14 |
| calibration 꼬리를 가장 많이 차지한 ch16 제외 | 20 | 5 | 14 |

**뒷받침되는 해석:** ch16과 긴 분산창의 영향이 다른 채널의 이상까지 함께
누르는 구조임. 다만 채널을 버리는 것은 해결책으로 채택하지 않았음. 그 채널에
실제 이상이 생기면 놓칠 수 있기 때문임. 두 실험은 같은 alpha지만 실제 정상
경보 예산까지 같지는 않으므로 성능 우열 실험으로 보지 않음.

다음 수정은 채널별 정상 빈도를 먼저 반영한 뒤 사건 점수를 합치는 방법과,
연속60틱을 하나의 변화로 보는 보정 방법을 따로 비교해야 함. Train 안의 별도
시간 구간에서 경보 수와 경보 지속시간을 함께 검사해야 함.

## 2. machine-1-6: 단순한 작은 분모 오류보다 정상 상태 변화가 큼

전체 test에서 GT-normal 시점의65.67%에 high가 켜짐. 정상 경보 시점13,082개 중
12,470개에서 ch13이 최고 점수를 냄. 약95.3%임.

Ch13의 실제60틱 분산을 log 변환 전, 원래 데이터 단위로 되돌렸음.

| ch13의 실제 분산 | 값 |
|---|---:|
| calibration 분산95% 분위수 | 0.0000534 |
| ch13이 최고 점수를 낸 정상 경보 시점의 분산 중앙값 | 0.0024871 |

후자는 전자의 약46.6배임. 서로 다른 표본의 요약값 비교이며 효과 크기의 추정치로
사용하면 안 되지만, 실제 변동폭 자체가 달라졌다는 근거임. 해당 feature scale도
1e-8 바닥값에 걸리지 않았음. 작은 분모를 고치는 것만으로 끝낼 문제는 아님.

Calibration 전체에서 variance60이 최고 성분인 비율은22.3%였지만 test GT-normal은
79.3%, GT-anomaly는83.0%였음. 이 성분이 이상도 잘 드러내지만, 새로운 정상 상태도
계속 이상처럼 보는 것임. 이 비율은 최대 성분의 기술적 귀속이며 causal importance가 아님.

**수정 방향:** 정상 상태를 하나의 고정 분포로 볼 수 있는지 먼저 확인해야 함.
새 상태에 근거가 부족하면 무조건 정상으로 적응하거나 무조건 이상으로 확정하지
않고, 분포 변화 및 reference 부적합을 함께 전달하는 편이 타당함. 관계 점수도
새 상태에서 신뢰 가능한지 별도 검증해야 하며, 이번 결과로 관계 모델이 해결한다고
주장할 수는 없음.

## 3. 성분을 빼면 좋아지는지: 오탐 시간과 오탐 개수가 반대로 움직임

machine-1-6에서 확인한 결과임. 각 실험은 같은 train 구간에서 재보정했음.

| 진단 실험 | 정상 시점 high 비율 | high 구간 수 | GT에 닿은 개수 /30 | 일대일 대응 /30 | GT와 안 겹치는 구간 |
|---|---:|---:|---:|---:|---:|
| 원래 dynamic 결합 | 65.67% | 92 | 29 | 17 | 65 |
| variance60 제외 | 29.52% | 979 | 29 | 29 | 871 |
| variance60만 사용 | 72.81% | 9 | 24 | 2 | 7 |

짧은 성분만 쓰면 경보 시간이 줄어도 작은 경보가 너무 많이 생김. 긴 성분만 쓰면
경보가 넓게 붙어서 여러 실제 이상을 하나의 후보로 덮음. 따라서 “오탐이 줄었다”는
말에도 정상 경보 시간·구간 수·중복 경보·경계 정확도를 함께 써야 함.

원래 결합에서도 GT29개와 겹치지만 일대일로17개만 대응됨. 이는 VLM 입력에
들어올 기회와 사건별 탐지 성공이 다르다는 뜻임. 단순 gap 병합을 다시 넣는다고
해결되지는 않음. 시작·유지·종료 판단을 분리한 사건 추출을 정상 train 경보 예산과
함께 검증해야 함. 이후에는 GT 경계와의 오차와 overlap 비율도 추가해야 함.

## 4. 화면 비용: threshold 왕복과 근접 후보를 구분해야 함

| 장비 | high run | review run | high·review 합집합 run | 화면 수 | 같은 시점 평균 표시 횟수 |
|---|---:|---:|---:|---:|---:|
| 1-1 | 103 | 224 | 128 | 383 | 3.34 |
| 1-2 | 0 | 652 | 652 | 652 | 6.25 |
| 1-6 | 92 | 157 | 74 | 348 | 3.32 |

평균 표시 횟수는 총 화면 틱 수 / 실제 표시된 고유 틱 수임. VLM 품질 지표는 아님.
1-1은high↔review 인접 전환199회,1-6은175회임. 하나의 연속 후보 안에서 band가
오갈 때 별도 parent가 생겨 화면이 늘어나는 부분이 있음.
반면1-2는 band 전환이0회인데도652개임. 이 장비는 review 자체가 끊기며 근접한
224틱 화면들이 겹치는 문제임. 두 비용 원인을 같은 병합 규칙으로 처리하면 안 됨.

**수정 방향:** 점수 mask와 사건 후보를 그대로 보존하면서, Stage2에 보여줄 화면을
중복 제거하는 스케줄을 먼저 분리해야 함. 한 장이 여러 parent를 대표하면 각
parent와 채널 증거의 대응을 유지해야 함. 화면을 합쳤다고 최종 이상 구간을 넓혀서는 안 됨.

## 5. Reference: train과 다르다는 것만으로는 이상이라고 못 함

각 false high 구간의 최고 점수와 각 GT의 최고 점수를 골라, 해당 채널의60틱을
train bank와 비교했음. 높이 포함 거리, 평균을 뺀 모양 거리, 차분 거리를 따로 계산함.
48틱 이전 문맥으로 고른 reference와, focus를 직접 보고 고른 최근접 사례도 분리했음.
후자는 원인 분석 전용이며 실제 입력 참조 선정에 사용하면 안 됨.

특히 train 앞50%의 정보 부족인지 확인하려고 전체 train bank도 사후 대조했음.

| 동일 채널의 정상 high 사례 | 사례 수 | 앞50% bank 최근접 거리 중앙값 | 전체 train bank 최근접 거리 중앙값 |
|---|---:|---:|---:|
| 1-1 ch24 | 30 | 17.23 | 4.67 |
| 1-6 ch13 | 27 | 19.10 | 13.81 |

거리는 fit에서 정한 scale을 적용한60틱 RMSE임. 서로 다른 채널끼리 수치를 비교하면
안 됨. 가까운 패턴이 있다는 사실도 정상이라는 증명은 아님. 앞50%만 보면 놓치는
정상 사례가 분명히 있지만, 전체 train을 본다고 모두 설명되는 것도 아님.

**기존 설명을 수정해야 함:** 모든 false high를 “평소 반복 spike를 못 알아본 문제”로
묶으면 부정확함. 일부는 정상 train의 뒤쪽에만 있는 패턴이고, 일부는 bank 안에서
충분히 설명되지 않는 정상 상태 변화임. 반대로 실제 이상 event 안에서 최고점을
낸 채널이 train과 가까운 사례도 있음. 그 채널이 정답 이상 채널이라는 보장은
없으므로, 채널별 유사도 하나로 event 전체를 정상/이상 확정하면 안 됨.

**수정 방향:** reference의 유사도·표본 수·상태 일치도를 함께 전달하고, 참조가
부적합하면 그 차이를 이상 근거로 과신하지 않게 해야 함. Train 앞부분으로 만든
고정 모델의 일반화 평가와, 전체 train으로 다시 학습한 모델의 평가는 분리해야 함.

## 이번 분석을 바탕으로 한 우선순위

1. **보정:** 한 채널의 한 큰 정상 변화가 다른 채널까지 누르는 구조를 분리 검증함.
   채널별 보정과 시간 의존성을 고려한 사건 보정을 하나씩 비교해야 함.
2. **사건 추출:** raw score는 유지하면서 시작·유지·종료 규칙을 따로 평가함.
   정상 경보 시간과 개수 중 하나만 개선된 것을 성공으로 보지 않음.
3. **참조 신뢰도:** 상태가 다른 reference를 이상 판정 근거로 확정하지 않게 함.
   충분한 정상 근거가 없는 상태는 별도로 표시해야 함.
4. **화면 비용:** 같은 증거를 반복해서 보내는 부분을 줄이되 채널·사건 coverage를 보존함.

## 검증 범위와 재현 파일

- 전체 test 길이로 분석했음. 앞 보고서의 기존 모델 공통 prefix 비교와 수치가
  조금 다름. 예:1-6 high는90개가 아니라92개임. Dynamic 첫59틱은 제외했음.
- GT는 사후 분석에만 사용했음. Alpha sweep으로 test 최적 threshold를 선정하지 않았음.
- 성분·채널 제거는 진단적 개입이며 실제 모델에 반영하지 않았음. 최대값 귀속에서
  동점은 고정 순서로 처리하므로 일부 성분 비율이 영향을 받을 수 있음.
- Train 유사도는 단일 채널·고정60틱·stride14의 제한된 분석임. Retrieval 거리의
  통계적 정상성 검정이나 다변량 관계 분석을 대체하지 않음.
- 기존24개와 분석용5개를 합쳐29개 테스트 통과했음. 현재 detector/threshold와
  이전 실행 결과를 바꾸지 않았음. ASD, 전체 SMD, VLM 재평가는 포함하지 않았음.
