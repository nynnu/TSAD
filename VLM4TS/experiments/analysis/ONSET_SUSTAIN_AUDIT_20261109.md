# 시작점과 유지 구간 분리 실험

## 목적과 방법

기존 통계 실험의 high/review 마스크를 합친 뒤 세 가지를 비교함. GT는 결과 평가에만 사용했음. 이 마스크의 연속 구간은 원래 Stage1 JSON의 후보와 1:1이 아닐 수 있음.

1. 기존 마스크.
2. 기존 연속 구간에 점수 기여 채널의 급변 단서가 있으면 첫 단서부터 끝까지 유지. 단서가 없으면 구간을 보류 상태로 그대로 유지.
3. 2번의 시작 이후 급변 단서 또는 train 기준을 넘는 절대 수준이 있는 틱을 유지하고 2틱 이하의 내부 빈틈만 메움. 기준은 앞 50% train과 다음 train 구간의 채널별 99% 분위수 중 큰 값임. 학습에 쓰인 앞부분을 재사용하므로 독립적 보정이나 오류율 보장은 아님.

3번의 절대 수준은 모든 채널 중 하나가 기준을 넘는지 보는 탐색적 방식임. 시작점의 원인 채널과 유지 점수의 채널을 연결하지 못하고 정상 상태 변화를 배제하지 못함. 또한 미래 틱을 보고 빈틈을 메우는 사후 처리이므로 온라인 탐지로 주장할 수 없음. 어떤 방법도 최종 시스템에 채택하지 않았음.

## 주요 결과

| 지표 | 기존 | 시작점 이후 | 시작점 + 절대 수준 |
|---|---:|---:|---:|
| machine-1-6: GT가 아닌 틱 중 표시 비율 | 86.54% | 86.44% | 85.82% |
| machine-1-6: 가장 긴 연속 표시 | 20,714틱 | 20,714틱 | 20,398틱 |
| machine-1-6: GT 비중첩 연속 조각 | 53 | 53 | 75 |
| machine-1-6: GT 표시 틱 | 3,702/3,708 | 3,702/3,708 | 3,701/3,708 |
| machine-1-2: GT 표시 틱 | 219/542 | 216/542 | 216/542 |

시작점만 조정하면 긴 구간은 거의 그대로임. 절대 수준을 유지 조건으로 추가해도 긴 구간 대부분이 남고, 정상 구간 조각 수가 늘었음. 점수 자체가 정상 상태에서도 오래 유지되는 문제를 해결하지 못함. 시작점 기준을 높여 정상 후보를 강제로 삭제하지 않았으므로 이 결과를 event 판정 성능으로 해석하면 안 됨.

기존에 조사한 machine-1-6의 정상 점수는 ch13과 자주 함께 나타났으나 관련성일 뿐 단독 원인으로 확정할 수 없음. 다음에는 시작 채널과 유지 채널의 연결, 운전 상태별 정상 이력, 독립 정상 기간의 안정성을 함께 확인해야 함. 새로운 유지 점수를 무작정 더하지 않고, 현재 채널의 수준이 어떤 정상 상태와 비교되는지부터 확인할 필요가 있음.

3개 장비는 앞선 분석에 사용된 개발 데이터이며, ASD나 미확인 장비의 일반화 결과가 아님. 선택한 99%와 2틱은 검증되지 않은 실험 설정임. 도식의 GT는 사후 평가용이며 모델 입력이 아님. 코드 `audit_onset_sustain.py`, 결과 `results/onset_sustain_20261109/summary.json`, 그림 `overview.png`. 보류 후보 보존 및 경계 이탈 방지 단위 테스트 3개 통과.

## Case 43 확대 범위 재확인

`case43_scope.png`에서 원래 후보 [637,651)와 다음 후보 [652,669), 각 채널의 확대 범위를 같은 시간축에서 확인함. 앞 후보 ch14·ch0 확대 화면이 뒤 후보의 큰 변화를 포함함. ch8·ch12는 앞 후보의 선택 채널에 없고 뒤 후보에서 선택됨. 따라서 앞 후보의 화면을 보고 뒤 변화의 증거까지 앞 후보에 귀속시키면 안 됨. 두 후보를 무조건 병합하거나 앞 후보를 뒤로 이동시킬 근거도 아님.

`stage2/candidate_scope_audit.py`는 한 페이지의 채널별 확대 범위가 다른 Stage1 후보와 겹치는 경우를 GT 없이 기록함. 사례 43에서는 뒤 후보가 8개 확대 범위에 들어옴. 이 표시는 검토 범위가 모호하다는 진단이며, 자동 판정이나 수정이 아님. 현재 `analysis/yellow_only_demo.py`에서 별도 JSON으로 저장하고, 기본 Stage2 모델 입력과 최종 집계에는 아직 반영하지 않음. VLM의 실제 구간 귀속을 고쳤다는 근거는 아직 없으며, 구간 표식을 제거한 화면에서 구간별 판단을 안전하게 연결하는 방식은 별도 검증이 필요함.
