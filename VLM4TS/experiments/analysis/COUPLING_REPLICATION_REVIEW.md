# 동시성 감소가 다른 event에서도 재현되는가 — 2026-11-05

**결과: 일부 재현됐지만, 새로운 정상 상태의 오탐 검증은 통과하지 못했음.**
따라서 동시성 감소를 단독 이상 판정이나 기존 점수의 무조건 추가 항으로 채택하지 않음.
현재 detector·threshold·Stage2 판정은 바꾸지 않았음.

## 1. 개발 사례와 분리해서 검사했음

- 앞서 본 machine-1-1/1-2/1-6을 제외한 SMD25개 장비를 모두 검사했음.
- 현재 동시성 가설에 대해 장비를 분리한 검증임. 프로젝트 전체에서 처음 본
  데이터라는 뜻은 아니며, 다른 데이터셋으로의 일반화 검증도 아님.
- Train 앞30%에서 채널별 peer2개와 상관 방향을 고정했음. 이후30~50%에서
  정상 관계가 유지되는 채널만 평가했음. Test를 보고 peer를 고르지 않았음.
- 50~75% 정상 train의 하위 꼬리로 alpha=.05 기준을 고정했음.
  마지막25%의 정상 경보율이10%를 넘는 채널을 제외하는 audit gate도 별도로 비교했음.
- 정상/이상은 같은 채널에서 평균과 표준편차를 맞춰 비교했음. 원래 ch13 비교의
  평균 차이≤.25 pooled SD, SD비율≤1.25 조건을 그대로 사용했음.
- 여러 창·채널의 결과를 **point GT event 한 개의 중앙 변화량**으로 합쳤음.
  같은 event를 창 수만큼 중복 성공으로 세지 않았음.

동시성 점수는 train에서 정한 부호를 맞춘 두 peer Spearman 상관의 평균임.
양·음의 정상 관계를 모두 처리하되, 창 안에서 한 채널이 일정하면 평가 불가로 둠.
Calibration 창20개 미만인 채널도 평가 불가이며 이를 정상으로 처리하지 않았음.

## 2. 데이터 준비 과정에서 확인한 문제

로컬에 없던11개 interpretation 파일은 공식 배포 저장소의 고정 commit에서 별도
출력 폴더로 받았음. 기존 데이터 파일은 수정하지 않았고 URL·SHA256을 남겼음.
출처: [OmniAnomaly SMD interpretation labels](https://github.com/NetManAIOps/OmniAnomaly/tree/7fb0e0acf89ea49908896bcc9f9e80fcfff6baf4/ServerMachineDataset/interpretation_label).

25개 장비에는 point GT279개가 있었음. 일치하는 채널 라벨이 있는 독립 point
event는276개였음.2개는 대응 채널 annotation이 없고, machine-2-3의 한 annotation은
point label보다9틱 길어 양성 분석에서 제외했음. 모순 구간은 정상 대조군에서도 제외함.
일부 채널 annotation은 같은 긴 point GT 안의 부분 구간이어서 event 집계 시 묶었음.
채널별 양성 창 자체는 실제 annotation이 있는 시간에서만 뽑았음.

이 준비 과정에서 분석 기준을 바꾼 것은 라벨 일치·사건 중복 처리뿐임.
결과를 본 뒤 peer 수·alpha·매칭 조건을 다시 맞추지는 않았음.
분석 규칙과 데이터 점검 내용은 `COUPLING_REPLICATION_PROTOCOL.md`에 기록했음.

## 3. 동시성 감소: 같은 방향은 많았지만 효과는 작아졌음

| 확인한 항목 | 224틱 | 60틱 |
|---|---:|---:|
| 짝 비교가 가능했던 장비 | 14개 | 20개 |
| 짝 비교가 가능했던 독립 GT event | 22개 | 55개 |
| 창·채널 짝 수 — 독립 event 수와 다름 | 92쌍 | 721쌍 |
| 동시성이 낮아진 event | **16/22 (72.7%)** | **37/55 (67.3%)** |
| event별 동시성 변화량 중앙값 | **-.0345** | **-.0026** |
| 변화량이-.1 이하인 event — 사후 크기 요약, 판정 기준 아님 | 6개 | 6개 |

모든276개 event를 매칭한 수치가 아님. 충분히 긴 채널 양성 구간이 있고,
정상과 높이·변동폭을 맞출 수 있는 사례에 한정됨.224틱에서는 길이224틱 이상
event30개 중22개,60틱에서는 길이60틱 이상77개 중55개를 비교했음.
매칭이 안 되는 event를 실패나 성공으로 임의로 채우지 않았음.

처음 ch13에서 본 .3 안팎의 상관 감소가 공통적으로 나타난 것은 아니었음.
특히60틱 변화량 중앙값-.0026은 매우 작음. **감소 방향의 재현과 실용적인 분리력을
구분해야 함.** 이상인데 상관이 유지되거나 더 강해지는 반례도 있었음.

Entity별 감소 비율을 동일 가중한 평균은224틱75.0%,60틱67.5%였음.
Entity를 재표집한 탐색적 bootstrap95% 구간은 각각53.6~96.4%,52.9~80.4%로 넓음.
이 범위를 유의성 확정이나 detector 성능 근거로 사용하지 않음. 개발 진단에서
선택한 가설이고, 매칭 가능한 일부 event만 포함되는 제한이 있음.

## 4. 새로운 정상 상태에서도 경보가 발생했음

새 정상 상태는 GT-normal 창의 mean 또는 SD가 정상 calibration의5~95% 범위를
벗어나는 경우로 기술적으로 분류했음. 이 상태 구분을 detector cutoff나 gate에
사용하지 않았음. 아래는 **평가 가능한 채널×창**을 합친 경보 비율이며 point-wise
FPR이나 event precision과는 다름.

| 정상 구간 종류 | 224틱, gate 없음 | 224틱, audit 통과 채널만 | 60틱, gate 없음 | 60틱, audit 통과 채널만 |
|---|---:|---:|---:|---:|
| Calibration 범위 안의 정상 | 4.18% | 2.78% | 4.89% | 3.95% |
| **새 정상 상태** | **10.37%** | **6.32%** | **12.31%** | **7.84%** |
| 전체 정상 | 6.67% | 4.18% | 7.54% | 5.26% |

Audit gate는 도움이 됐지만 새 정상 상태의 경보가 더 많다는 문제는 남았음.
장비를 동일 가중하면 새 정상 상태 경보율은 gate 후에도224틱7.74%,60틱8.18%임.
평균 뒤에 숨는 실패도 컸음.224틱 gate 후 machine-1-3은35.2%,1-4는31.1%였음.

Gate의 비용도 있음.224틱 평가 가능 채널531개 중479개,60틱511개 중448개만
남겼음. 비교 가능한 event도22→20개,55→51개로 줄었음. 전체25×38=950개
entity-channel 모두를 평가한 모델이 아니며, 평가 불가 채널을 정상으로 간주하면 안 됨.

채널 하나라도 경보면 창 전체를 이상이라고 하는 경우도 따로 계산했음.
Gate 후에도 정상 창 중 그런 창의 비율을 장비별 평균하면224틱33.3%,60틱40.9%임.
따라서 채널별 alpha=.05를 여러 채널에 적용한 뒤 any-channel로 합치는 것만으로는
event 오탐 제어가 되지 않음. 이 수치는 Stage1+Stage2 최종 성능이 아님.

## 5. 반례를 실제 그림으로 확인했음

### 이상인데 관계가 더 강해진 사례

Machine-2-1의 ch8에서 평균 차이.108 pooled SD, SD비율1.009인 짝을 확인했음.
정상 coupling은.904, 실제 이상은.942였음. 상관을 깨는 이상만 존재하는 것이 아님.
주변 채널들이 같이 변하거나 함께 이상을 보이면 동시성이 유지될 수 있음.
이는 원인 채널 식별을 의미하지 않음.

![동시성 감소가 나타나지 않는 이상](results/coupling_replication_smd25/counterexample.png)

### 정상인데 높은 상관을 두고도 경보가 나는 사례

Machine-1-3 ch20의 `[18032,18256)`은 focus와 앞뒤 문맥이 모두GT-normal이고,
정상 train audit도 통과한 채널이었음. 그런데 coupling .978에도 p=.037로 경보가 났음.
정상 calibration26개 창의 coupling 최솟값은.989, 중앙값은.998이었기 때문임.

그림에서는 여전히 거의 같이 움직임. 즉 **“정상 train에서 통계적으로 드문 작은
차이”를 “실질적인 관계 붕괴”로 해석하는 문제**가 있음. 새 정상 상태, 거의
중복된 채널의 미세 잡음 차이, 짧은 calibration 표본의 한계가 함께 영향을 줄 수 있음.
이것이 단순 p-value만 이상 판정에 쓰면 안 되는 직접적인 반례임.

![새 정상 상태의 false alarm](results/coupling_replication_smd25/normal_state_false_alarm.png)

사례는 사후 설명용임. 재현 방향 사례는 event 중앙 변화량 근처의 짝,
반례는 감소하지 않은 event의 대표 짝, 정상 오탐은 gate 후 새 정상 오탐률이
가장 높은 장비의 시간순 중간 사례를 골랐음. 모든 선택 정보는case_selection.json에 남겼음.

## 6. 짧은 이상과 coverage 제한도 남음

고정 창의 상관계수는 짧은 spike를 주변 정상값과 섞어 계산함.
14틱 미만 event는135개로 분석 가능한276개 중 약49%였음.60틱 중앙 창을
GT로 미리 지정해도, 해당 채널 중 경보가 하나라도 난 event는20개뿐이었음.
이 수치는 GT 시간·채널을 미리 아는 조건부 진단이며 end-to-end recall이 아님.
대신 긴 구간만 비교한 결과를 전체 이상에 일반화하면 안 된다는 근거임.

## 7. 이번 판단과 다음 설계의 조건

| 검증 질문 | 판단 |
|---|---|
| 다른 event에서도 동시성 감소가 나타나는가 | **일부 재현됨. 다만 효과가 작고 반례가 있음** |
| 새 정상 상태를 이상으로 잡지 않는가 | **통과하지 못함** |
| 정상 train audit를 거치면 완전히 해결되는가 | **아님. 오탐은 줄지만 coverage가 줄고 상태 변화 오탐이 남음** |
| 현재 동시성 점수를 단독 탐지 또는 무조건 추가 항으로 채택할 수 있는가 | **보류** |

다음에는 관계의 드묾만 보지 말고, 의미 있는 변화 크기와 해당 정상 상태를
설명할 근거가 함께 있는지 확인해야 함. Peer가 거의 복제 채널인 경우 작은
잡음 차이에 p가 과민해지는지도 별도로 구분해야 함. 동시에 동시성이 유지되는
진짜 이상과 짧은 이상을 기존 marginal 증거가 보존하도록 해야 함.
이 결과를 본 뒤 같은25개 장비에서 threshold를 골라 개선됐다고 주장하면 안 됨.
