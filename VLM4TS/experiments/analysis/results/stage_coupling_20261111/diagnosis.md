# Stage1 ↔ Stage2 연결 점검 (2026-11-11)

분류: Ablation(구조 점검). 코드: `audit_stage_coupling.py`. 28개 장비, VLM 호출 없음. GT는 평가에만 사용. 최종 파이프라인이 전체 장비에서 끝까지 실행된 적이 없어 상호작용은 구조와 저장된 후보로 측정함.

## Stage1이 내보내는 것과 Stage2가 쓰는 것

| Stage1 출력 | Stage2에서의 사용 | 측정 |
|---|---|---|
| 채널 목록과 순서 | 8개씩 페이지로 나눔(순서만 사용) | 후보의 64%가 2쪽 이상, GT 채널의 33%가 2쪽 이후 |
| `zoom_center` | 후보 구간 안이면 그대로 사용 | 12,676개 채널 행 중 98.8%가 Stage1 위치 유지, 1.2%만 Stage2 자체 위치 |
| `zoom` 범위 | 읽지 않음 | |
| `spike_score`, `deseason_score` | `source_scores`에 복사만 하고 화면·prompt·집계 어디에도 안 씀 | Stage1 점수의 GT 채널 구분력 AUROC 0.80 |
| `source` (spike / both / deseason) | 그림 제목 글자로만 사용 | GT 채널 비율: both 72%, spike 45%, deseason 30% |
| `config` 임계값 | 계획에 저장만 함 | |
| (Stage2 → Stage1) | 되돌아가는 정보 없음. 판정이 Stage1 순위나 경보량을 바꾸지 않음 | |

Stage1의 신뢰도 정보(점수, 출처)가 Stage2에서 모두 버려지고, 모든 후보가 같은 무게로 판단됨.

## 서로 다른 단위

- Stage1 후보는 14틱 열 조각(중앙값 14틱, 66%가 정확히 14틱). Stage2는 최대 164틱 core를 224틱 화면으로 판단. GT 이상 core가 속한 사건은 중앙값 56틱, 43%가 100틱 초과. 에피소드의 한 조각씩 따로 판단하는 구조.
- 연속한 후보 사이 간격이 224틱 미만인 비율 41.7%. 그래서 core의 41%가 "다른 후보가 보임"으로 표시됨.
- 인접 후보를 간격 224틱 이하로 묶으면 판단 단위가 1,039 → 608개(−41%), GT와 겹치는 단위 비율 0.396 → 0.451, 사건 재현율은 0.875 그대로. (묶은 구간 전체를 경보로 내면 틱 정밀도는 0.346 → 0.255로 하락하므로 판단 단위로만 쓰는 경우의 수치임)

## 서로 다른 "정상"의 정의

- Stage1: 이 test 시계열 자체의 중앙값/MAD (test를 본 뒤 보정). Stage2: train에서 찾은 비슷한 구간.
- Stage2 참조가 지원되는 비율: GT 후보 48%, 비GT 후보 52%. 둘을 구분하지 못하고, 전체의 절반이 지원되지 않음.
- "seasonal residual" 출처 채널은 참조 지원이 36%로 spike 출처(56%)보다 낮음. 같은 그림에 "seasonal residual"이라는 제목과 "no stable period"라는 부제가 함께 나옴.
- 주기 추정이 두 곳에서 따로 이루어짐. 872개 채널 중 Stage1은 94%에서 주기를 찾고 Stage2는 14%. 둘 다 찾은 117개 중 같은 주기는 44개(38%).
- Stage1 `period()`는 FFT 최댓값 ≥ 중앙값의 3배를 기준으로 하는데, 길이 28,000의 백색잡음에서 100%, 길이 6,000에서 88%, 2,000에서 54%가 "주기 있음"으로 나옴(AR(0.95), random walk는 항상). 긴 시계열에서 이 기준은 의미가 없고, 탈주기 후보의 정밀도가 낮은 것과 일치함(deseason만으로 뽑힌 채널은 비GT가 70%). 구간 선택에는 거의 영향이 없음(deseason만으로 만들어진 구간은 5개).

## 잘 이어지는 것

- Stage1이 준 확대 위치를 Stage2가 98.8% 그대로 씀.
- Stage1이 사건의 87.5%와 정답 채널의 96%를 후보에 담음. 채널 순서는 의미 있음(AUROC 0.80).

## 한계

- 참조 지원 비교는 51개 후보(채널 행 317개)이고, 다른 항목은 28개 장비 전체의 저장된 후보 기준.
- 이 점검은 연결 구조를 측정했을 뿐, 어떤 수정이 오탐을 줄이는지는 아직 측정하지 않음.
