# Stage2 시험: 보류 편향 제거와 반복 이력 표시 (2026-11-10)

분류: Ablation. 코드: `stage2_history_test.py`. machine-1-x에서 seed 1로 뽑은 한 쪽짜리 후보 27개(GT 12, 비GT 15; 조건을 만족하는 후보가 부족한 장비가 있어 32개를 채우지 못함). gpt-4o 81회.

## 조건

- base: 현재 HFZ 화면 + 현재 prompt(+index text)
- prompt: 같은 화면 + 보류로 미는 문장을 뺀 짧은 prompt
- history: 새 prompt + 후보 직전 2,000틱과 현재 화면을 이어 그린 그림 + 같은 크기 변화의 과거 횟수

## 결과 (페이지 판정 그대로, 인접 후보 보류 규칙 미적용)

| 조건 | GT 12개: 이상 / 정상 / 보류 | 비GT 15개: 이상 / 정상 / 보류 |
|---|---|---|
| base | 2 / 0 / 10 | 3 / 0 / 12 |
| prompt | 9 / 3 / 0 | 12 / 3 / 0 |
| history | 8 / 4 / 0 | 9 / 6 / 0 |

- prompt를 고치면 보류가 사라지지만 그 표가 거의 전부 "이상"으로 감. GT 75%, 비GT 80%로 구분 없음.
- 이력을 보여주면 비GT 6개가 정상으로 넘어가지만 GT도 4개가 넘어감. 이상 판정 비율 GT 67%, 비GT 60%. 27개 표본에서 의미 있는 차이가 아님.

## 그림 확인

- `machine-1-4.e00004...history.png` (GT, history 조건에서 정상 판정): ch14·11·15·12에 과거 2,000틱의 어떤 spike보다 5~10배 큰 burst. 사람 눈에는 명백히 새로운 변화. VLM이 평소의 작은 주기 spike와 같은 것으로 읽음. 분류: VLM 판독 실패.
- `machine-1-7.e00013...history.png` (비GT, 이상 판정): ch16이 2,000틱 동안 평평하다가 0.65까지 한 번 튐. 이력상 처음 보는 변화이고 라벨은 정상. 화면만으로는 이상이 아니라고 할 근거가 없음. 분류: 라벨과 신호의 불일치.

## 같은 정보를 숫자로 계산하면

후보 안 최대 변화 ÷ 직전 2,000틱의 최대 변화(화면에 보인 채널 중 최댓값):
- 이 27개에서 AUROC 0.467. 1 이상인 후보가 GT 9/12, 비GT 11/15.
- VLM의 history 판정은 이 비율을 대체로 따라감(비율이 큰 쪽은 이상, 1 근처는 정상). 즉 VLM은 이력을 읽었고, 읽은 정보 자체가 GT와 비GT를 가르지 못함.

Stage1이 고른 비GT 후보는 최근 이력 기준으로도 GT만큼 "새로운" 변화임.

## 결정

- 새 prompt는 채택하지 않음. 보류를 없애는 대신 비GT의 80%를 이상으로 확정함.
- 이력 화면도 채택하지 않음. 구분력 근거 없음.
- 한계: 27개, 조건당 1회 호출, history 조건은 화면과 횟수 text를 동시에 바꿈. 평평한 채널은 횟수가 2,000으로 나와 text 근거로서 잡음이었음.
