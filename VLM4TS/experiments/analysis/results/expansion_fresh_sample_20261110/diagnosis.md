# 미탐 분리 집계 + 채널 확장 대조 실험 (2026-11-10)

분류: Ablation. 코드: `audit_miss_funnel.py`, `expansion_fresh_sample.py`, `audit_regime_evidence.py`.

## 1. 정답 채널이 어디서 빠지는가 (28개 장비, VLM 호출 없음)

채널 라벨이 정확한 225개 사건의 정답 (사건, 채널) 쌍 1,496개 기준.

| 단계 | 개수 | 비율 |
|---|---|---|
| Stage1이 사건 자체를 놓침 | 93 | 6.2% |
| 사건은 잡았지만 상세 화면에 채널이 없음 | 75 | 5.0% |
| 상세 화면에 표시됨 | 1,328 | 88.8% |

전 채널 확장 비용은 +3,800쪽(기존 2,026쪽), 변화량 상위 8개만 추가하면 +1,044쪽으로 75개 중 34개가 화면에 들어옴.

## 2. 같은 후보에서 채널을 늘렸을 때 (새 사례 24개, gpt-4o 48회)

이전 실험에서 본 적 없는 6개 장비에서 무작위(seed 0)로 GT 겹침 12개, 비겹침 12개. 기본 쪽과 추가 쪽(미표시 상위 8채널) 모두 index text 포함.

| | 기본 쪽만 | 추가 쪽 포함 |
|---|---|---|
| VLM 선택 채널 TP / FP | 8 / 19 | 8 / 20 |
| 확정 채널 TP / FP | 4 / 10 | 4 / 10 |
| GT 후보 12개 중 이상 확정 | 2 | 2 |
| 비GT 후보 12개 중 이상 확정 | 3 | 3 |

- 추가 쪽에 정답 채널 16개가 새로 들어갔지만 VLM은 0개 선택. 추가 쪽 24장 전부 `uncertain`.
- 기본 쪽 VLM 판정은 GT/비GT가 똑같이 anomalous 4, uncertain 8. `normal_repeat`은 0회.
- 표시된 정답 채널 48개 중 선택 8개(17%).

## 3. 그림으로 본 원인

- `machine-2-9.e00014` (GT 253틱 지속 사건 안의 14틱 후보): ch 8·11·12·14가 화면 0~187틱 내내 train 중앙값보다 높다가 함께 내려감. 이상은 지속 상태인데 질문은 14틱 조각에 대한 것이고, prompt는 후보 밖 변화를 근거로 쓰지 말라고 함 → uncertain. 분류: 질문 단위 불일치(구조 문제).
- `machine-2-2.e00029` (GT 3틱): 107틱에서 ch 9·10·11·12·0 동시 spike. 같은 화면 55·62·167틱에 ch 9·10의 비슷한 spike가 있음(비GT). 화면만으로는 구분이 어려움 → uncertain. 분류: `non_stationary_noise`.
- 표본 GT 후보 12개 중 9개가 95~841틱 길이 사건의 14틱 이하 조각.

## 4. 추가 확인 (28개 장비 1,044개 후보, VLM 없음)

GT 겹침 후보와 비겹침 후보를 가르는 장비별 AUROC 평균:

- 후보 안 최대 변화량 ÷ train 99.9% 변화량: **0.765**
- 화면에서 train 0.1~99.9% 범위를 벗어난 시간 비율: 0.551 (28개 중 7개 장비에서만 더 높음)

"지속 상태 이탈이 구분 근거일 것"이라는 가설은 기각. 반대로 단순한 train 기준 변화량이 이 표본의 VLM 판정(4/12 대 4/12)보다 구분력이 있음. 단 AUROC는 전체 후보, VLM은 24개 표본이라 같은 집합 비교는 아님. 임계값 미조정, 탐색용.

## 결정

- 채널 확장: 닫음. 상한이 정답 채널의 5%이고 실측 이득 0, 비용 +52~188%.
- 병목은 Stage2의 사건 유효성 판단. 현재 prompt·집계에서 uncertain이 응답의 2/3이고, 인접 후보가 보이면(1,044개 중 429개) VLM 응답과 무관하게 보류됨.
- 한계: 한 쪽짜리 후보만 표본, 페이지당 1회 호출, GT 채널은 사건 단위 합집합.
