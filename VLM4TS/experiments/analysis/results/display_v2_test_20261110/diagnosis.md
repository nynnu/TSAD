# 화면 v2 비교 (2026-11-11)

분류: Ablation. 코드: `display_v2_test.py`. 코어 51개(14개 장비, GT 24 / 비GT 27), 코어당 gpt-4o 1회, `report` 정책으로 집계.
기존 응답과 v2 응답은 같은 페이지 내용·같은 prompt(+index text)이고, v2만 그림(회색 train 최소~최대 띠, heatmap 전 행 번호)과 prompt 한 문장이 다름.

| | GT 24개: 이상 / 정상 / 보류 | 비GT 27개: 이상 / 정상 / 보류 | 이상 판정 중 채널 정답 / 오선택 |
|---|---|---|---|
| 기존 화면 | 6 / 0 / 18 | 7 / 0 / 20 | 18 / 26 |
| v2 화면 | 8 / 0 / 16 | 13 / 0 / 14 | 30 / 38 |

- 판정이 바뀐 코어 12개: 보류→이상 10개(비GT 7, GT 3), 이상→보류 2개.
- 이상 판정의 GT 비율은 6/13(46%)에서 8/21(38%)로 내려감. `normal_repeat`은 양쪽 0.

원인 분류: 가설 실패(구현 문제 아님). 회색 띠는 "train이 여기까지 간 적 있다"를 보여 주도록 만들었는데, VLM은 이를 정상 근거로 쓰지 않았고 전체적으로 이상 쪽으로 판정이 이동했음. 이전 시험(prompt 변경, 이력 화면)과 같은 패턴이며, 화면 정보를 늘려서는 비GT 후보를 정상으로 내리지 못했음.
결정: 파이프라인 기본에서 제외(`--display-v2` 옵트인으로 보존). 한계: 표본이 작고 그림과 prompt 문장을 동시에 바꿨으며, 비교는 한 번의 호출씩임.
