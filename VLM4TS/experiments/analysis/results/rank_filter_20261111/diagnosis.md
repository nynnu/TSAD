# 장비 내 순위 필터 (개발 장비 machine-1-x 8개, 2026-11-11)

분류: Exploration. 코드: `rank_filter.py`. 후보(core) 1,044개 중 machine-1-x의 것만 사용(heldout은 실행하지 않음). VLM 없음.

각 장비 안에서 후보에 점수를 매겨 상위 비율만 남김(경보 예산). 점수는 장비별 백분위 순위의 평균.
특징: s1 = Stage1 점수, ratio = train 기준 최대 변화 비, costep = 함께 큰 변화를 보인 채널 수.

| 남기는 비율 | 무작위: 정밀도 / 사건 재현율 | costep: 정밀도 / 사건 재현율 / 사건 F1 | s1+costep |
|---|---|---|---|
| 1.00 (전부) | 0.540 / 0.830 | 0.540 / 0.830 / 0.654 | 같음 |
| 0.75 | 0.537 / 0.670 | 0.595 / 0.786 / 0.677 | 0.595 / 0.804 / 0.684 |
| 0.50 | 0.541 / 0.487 | 0.701 / 0.661 / 0.680 | 0.673 / 0.643 / 0.658 |
| 0.35 | 0.541 / 0.367 | 0.762 / 0.536 / 0.629 | 0.733 / 0.554 / 0.631 |

- 경보를 절반으로 줄여도 사건 재현율 0.83 → 0.66(무작위는 0.49), 정밀도 0.54 → 0.70. 장비 안에서는 순위가 실제로 신호를 가짐.
- 장비 내 AUROC 평균: costep 0.78, ratio 0.71, s1 0.69.

채택하지 않음. 이유: 점수 조합을 machine-1-x 결과로 골랐고(costep 선택), 특징도 SMD에서 본 패턴에서 나왔으므로 다른 데이터셋에서도 통하는지 모름. 사용자 지시(SMD 특화 금지, 근본 해결)에 따라 참고 증거로만 남김. 장비 내 순위 정규화와 경보 예산이라는 구조 자체는 일반적임.
