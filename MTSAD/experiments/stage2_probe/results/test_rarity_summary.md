# test 안에서만 비교 vs train과 비교 (2026-11-05)

코드: `../test_rarity.py` · 결과: `test_rarity.json` · machine 5대(1-8, 1-6, 2-9, 3-3, 3-5)의 Stage1 구간 160개

드묾 = 가장 비슷한 다른 창까지의 거리(구간 ± 10틱, 채널마다 중앙값 빼고 MAD로 나눔).
test 안 = 자기 주변을 뺀 test 전체에서 찾음(Matrix Profile discord와 같은 생각) / train 대비 = train 전체에서 찾음.

## 구간 단위 (GT 구간 96 vs 오탐 64) — AUC
| 점수 | AUC |
|---|---|
| test 안 드묾 | 0.481 |
| train 대비 드묾 | 0.496 |
| Stage1 spike 점수 | **0.671** |
| 후보 채널 수 | 0.663 |
→ 드묾으로는 GT 구간과 오탐 구간을 전혀 못 가름(0.5 수준). Stage1이 이미 "튀는 곳"만 골라서 오탐도 똑같이 드묾.

## 채널 단위 (GT 구간 안 후보 1581개, GT 736개) — AUC
| machine | test 안 | train 대비 | Stage1 spike |
|---|---|---|---|
| 전체 | **0.732** | 0.697 | **0.737** |
| 1-6 | 0.721 | 0.647 | 0.726 |
| 1-8 | 0.704 | 0.699 | 0.801 |
| 2-9 | 0.926 | 0.880 | 0.898 |
| 3-3 | 0.686 | 0.636 | 0.692 |
| 3-5 | 0.841 | 0.757 | 0.840 |
- test 안 비교가 train 비교보다 5대 모두 같거나 높음(+0.035) → train 오염의 영향으로 보임.
- 하지만 Stage1 spike 점수와 비슷(0.732 vs 0.737)하고, 두 드묾 점수의 상관이 0.86 → 같은 정보. 합쳐도 0.721로 이득 없음.
- GT 채널 736개 중 215개(29%)는 test 안에서도, train 대비로도 흔함(둘 다 하위 50%) → 드묾으로는 못 찾는 GT.
